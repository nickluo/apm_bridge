# 云台私有协议（实测修订版）

> **依据**：先飞机器人《云台私有协议》V1.0.4（2026.07，固件 V3.5+，实测样机 fw=38）
> ＋ **2026-10-26 C20S 立装真机台架实测**（角度/速率/FPV 阶跃闭环 + 三轮手动激励，探针脚本见 `test/gimbal_bench/`，方法记录见附录 C）。
> 适用机型：**C20S（单轴俯仰）/ C40D（两轴）/ C200T（三轴）**，三者坐标系与使用方式一致（已确认）。

## 3. 坐标系与符号约定（核心，实测定案）

### 3.1 坐标系

- **载机坐标系**：X 前、Y 右、Z 下（FRD 式右手系；附录1 图几何重建 + 实测自洽）。
- **相机坐标系**：与载机系同构，云台减震平台平行载机 XOY 面；立装/吊装由固件经 `inv_flag` 内部补偿，**上位机公式不随安装方式变化**（立装实测）。
- **欧拉旋转顺序**：Z → Y → X（原文附录2）。原文的 φ/θ/ψ 命名与惯用互换（φ 为俯仰、θ 为滚转），按实测直接给出结果域，勿按希腊字母直觉推导。

### 3.2 符号总表（正方向 = 绕该轴右手/罗盘约定的正转）

| 通道 | 域 | 正方向 | 依据 |
|---|---|---|---|
| `cam_angle[0]` 滚转姿态 | 欧拉 | **右滚** | 手动激励 3 轮（+28~+31°）[实测] |
| `cam_angle[1]` 俯仰姿态 | 欧拉 | **抬头** | 角度命令闭环 + 肉眼 [实测] |
| `cam_angle[2]` 偏航姿态 | 欧拉 | **右转（罗盘式）** | 手动激励 2 轮往返对称 [实测] |

| `cam_rate[1]` 滚转陀螺 | 陀螺 | **右滚**（与欧拉滚转同号） | 手动激励 3 轮 [实测] |

| `mtr_angle[2]` 偏航编码器 | 编码器 | 同上 | 同上 |

### 3.3 域间关系（实测公式）

```
cam_angle[1] ≈ −mtr_angle[0] + δ        δ = 水平基准慢漂 1~4°（无 uav 融合时）
cam_rate[0]  = −d(cam_angle[1])/dt      （俯仰反号）
cam_rate[1]  = +d(cam_angle[0])/dt      （滚转同号）
cam_rate[2]  = +d(cam_angle[2])/dt      （偏航同号）
偏航姿态漂移 ≈ −0.18°/s（无 uav 融合时，地面静止实测）
```

### 3.4 命令域（实测）

| 命令组合 | op_value 语义 | 正方向 | 实测精度 |
|---|---|---|---|
| 锁定 + 角度 | 期望相机姿态角 0.01° | **抬头正** | ±10/20/30° → 收敛 ±0.1° 内 |
| FPV + 角度 | 期望相机相对角 0.01° | **抬头正**（= **−编码器域**，精确驱动 `mtr → −op`；零点=编码器零点，非水平） | 收敛至 ±0.02° |
| 锁定/FPV + 真实角速度 | 期望角速度 0.1°/s | **抬头速率正**（= `d(cam_angle)/dt`） | +30°/s 严格积分 |
| 比例角速度 | ×倍率系数 | — | [未验证]（未使用） |
| 跟随模式 | — | — | [原文] 禁用于俯仰/滚转轴 |

**FLU（ROS）侧转换**（驱动 `gimbal.cpp` 现行实现，已验证）：

```
发布 angular_velocity (相机FLU) = [ +cam_rate[1], +cam_rate[0], −cam_rate[2] ] × 0.1°/s
相机位姿 (FLU)  = body ⊗ Rz(−mtr_yaw) ⊗ Rx(+mtr_roll) ⊗ Ry(−(−mtr_pitch))   （俯仰编码器取反入 FRD）
```

## 4. 命令行为（实测）

**FPV 跟随的重要实测结论（2026-10-27）**：无 uav 融合数据（valid=0）时，固件 FPV 模式**不随机身转动**（表现为 LOCK 式世界保持）。因此本项目的 AIM（机身 +Z 上视）实现为 **LOCK+真实角速度 + P(位置增益 `gimbal.aim_follow_gain`，默认 8) + FF(机身俯仰速率前馈)**，不依赖云台 FPV/uav 融合（约定 `send_uav_data` 恒 false）。真机实测（C20S）：跟随滞后 **~0.03s**（角度域方案为 0.15s），270°/s 手甩最差相对角 14.8° 且静止后完全恢复，静止段相对角 σ ≤ 0.07° 无振铃；速率通道 1:1 即时响应是低滞后的根基。

| 命令 | 行为 |
|---|---|
| 2 启动 | 上电自动启动；**STOP 后必须 START 才恢复受控**，实测 0.5s 内回平 [实测] |
| 3 停止 | 电机断电、增稳失效，相机会下垂；仅供通电存储场景 [原文][实测] |
| 4 手动 | 常态命令；`trig` 每包递增即可重复执行；命令 5/6 期间 gbc 速度应清零由固件闭环 [原文+驱动约定] |
| 1 陀螺校准 | 需 `tca_flag=1` 且云台静止，历时数秒 [原文] |
| 5/6 指点/内置跟踪 | `target_angle` 为目标偏离画面中心角（水平右正/垂直**下正**）[原文] |
| trig 规则 | 命令码变化立即执行；同码重复执行需变 trig [原文] |
| go_zero 回中位 | **真机 C20S (fw38) 完全无效**：单轴/三轴、0→1 边沿或持续置 1，均不触发回中动作，也不干扰后续控制命令（LOCK 速率/角度照常受理）。上电/START 的自动回平目标是 cam=0（水平，编码器停在水平偏置 ~+5-6°），**不是编码器零点** [2026-10-30 实测，probe_go_zero.py / probe_fpv_to_lock.py] |

**机械零点（编码器零点）回中原语（2026-10-30 实测定案）**：`FPV + 角度 op=0 + fl_sens=15` 精确驱动 `mtr → 0`（FPV 相对角零点 = 编码器零点），~80° 行程 0.2-1s 到位。驱动的启动回中（`gimbal.home_on_connect`）即用此原语；go_zero 边沿仅为其它机型兼容保留（~100ms 脉冲）。LOCK+角度 op 的目标域是 cam 姿态角（0=水平 ≈ 编码器 +5-6°），与编码器零点不同域，勿混用。

**fl_sens**（FPV 跟随灵敏度，仅 FPV 模式生效）：`0` 时相对角跟踪极慢（实测 ~0.2°/s 爬行，AIM 类应用不可用）；`15` 干脆收敛（实测 80° 目标 0.5s 内到位）。[实测]

**保护**：任意轴 FPV → 全轴 FPV 且倾角保护无效；俯仰/滚转轴禁用跟随模式 [原文]。样机已解除转动限制（实测 cam+108° 无保护触发）。

## 5. 使用注意（实测汇总）

1. **水平基准漂移**：无 uav 融合时姿态基准慢漂（1~4°，yaw −0.18°/s），FPV/编码器域不受影响，但 LOCK 姿态保持与 AIM 绝对精度受其限制（≈±2°）。任务前留自平时间。
2. **uav 融合**：`uav.angle`（滚转/俯仰/偏航）与 `accel`（NEU）的符号约定未实机验证——在按附录 C 方法判别前**务必 `valid=0`**。
3. **轴序陷阱**：发送包 gbc 槽序 [滚转,俯仰,偏航]；接收包 `cam_rate`/`mtr_angle` 是 [俯仰,滚转,偏航]，`cam_angle` 是 [滚转,俯仰,偏航]。
4. **俯仰双域陷阱**：编码器（低头正）与姿态角/命令 op（抬头正）反号；FPV 相对角命令 = −编码器。
5. **C40D/C200T 增补**：滚转/偏航编码器符号在单轴机不可测（恒 0），按机型一致性沿用俯仰的"编码器=低头正"假设；上电后建议先做小角度阶跃复验（附录 C.1）。

## 附录 C：台架判别方法（换机/换固件后复验用）

1. **角度域**：LOCK+角度 ±10° 阶跃，读 cam/mtr 收敛值 → 得姿态域符号与姿态↔编码器关系。
2. **速率域**：真实角速度 +30°/s ×3s，看 cam 积分方向与 cam_rate 读数 → 得速率命令域与陀螺域。
3. **FPV 域**：FPV+角度 ±20°（fl_sens=15），看 mtr 收敛 → 得相对角命令与编码器关系。
4. **绝对方向**：A/B 两段式 ±30° 摆动肉眼判别抬头/低头方向（唯一需要人眼的外部基准）。
5. **滚转/偏航**：手动右滚 20~30°、左偏航 60~90°（往返），对照 cam_angle/cam_rate 变化方向。
6. 工具：`test/gimbal_bench/`（协议探针 + 手动激励记录器）。
